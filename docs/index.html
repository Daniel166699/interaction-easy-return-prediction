CRITICAL REVIEW

关键局限

这是工程基线，不是可以直接用于市场有效性判断的最终实证模型。

文本时间可用性偏差

当前事件日按 question_time 确定，但文本包含回答内容。94.03% 的面板事件有回答，其中 85.76% 的回答晚于 query_date 15:00，回答延迟中位数为 56.6 小时。

缺少沪市与北交所

当前只覆盖深市主板和创业板，市场代表性有限。

控制变量不足

仅有总市值 size，缺少流通市值、BM、换手率、行业与市场收益。

收益极值未缩尾

样本仍存在极端日收益，MSE 与 R² 容易受异常值影响。

没有交易回测

尚未考虑交易成本、冲击成本、涨跌停与停牌约束。

NEXT STEPS

后续路线

  2. 02

    建立问题对照

    重新生成 question-only embedding，比较问题模型与 Q+A 增量信息。

  3. 03

    回答事件研究

    检验 CAAR、异常成交量、波动率与回答后漂移。

  4. 04

    补齐数据与稳健性

    增加沪市、流通市值、BM、换手率，并按训练窗口缩尾、去重和中性化。

  5. 05

    经济显著性

    十分组、多空组合、换手率、交易成本、容量和最大回撤。
